Q1. Define Universal Gates. Realize NOT, AND, OR, and XOR gates using NAND gates only (IC 7400) and NOR gates only (IC 7402). Also design a 2-switch staircase light controller using NAND gates only.7 Marks • Ajit QB & SPPU QB
SPPU Marking Split: Definition (1M) · NAND Realization Circuit & Equations (2.5M) · NOR Realization Circuit & Equations (2.5M) · Staircase Application (1M)

1. Definition / Core Principle: A Universal Gate is a logic gate using which any Boolean expression or any basic logic gate (NOT, AND, OR, XOR, XNOR) can be constructed without requiring any other gate type. NAND ($\overline{A\cdot B}$) and NOR ($\overline{A+B}$) are the two universal gates because each forms a functionally complete set via DeMorgan's duality.

Diagram Explanation (How to Describe in Exam)
  • NAND Realizations (Left): Tying both inputs of one NAND gives $Y=\overline{A\cdot A}=\overline{A}$ (NOT). Cascading a second NAND-as-NOT gives $\overline{\overline{AB}}=AB$ (AND). Inverting inputs first gives $\overline{\overline{A}\cdot\overline{B}}=A+B$ (OR via DeMorgan). For XOR, $g_1=\overline{AB}$, $g_2=\overline{A\cdot g_1}=A\overline{B}$ (inverted), $g_3=\overline{B\cdot g_1}$, and $g_4=\overline{g_2\cdot g_3}=A\overline{B}+\overline{A}B = A \oplus B$.
  • NOR Realizations (Right): Tying inputs of one NOR yields $\overline{A+A}=\overline{A}$ (NOT). Cascading a second NOR-as-NOT yields $\overline{\overline{A+B}}=A+B$ (OR). Inverting inputs first yields $\overline{\overline{A}+\overline{B}}=A\cdot B$ (AND via DeMorgan). A 4-NOR topology naturally produces XNOR ($\overline{A\oplus B}$), so a 5th NOR inverter yields XOR ($A \oplus B$).

3. Staircase Light Controller Design (Ajit QB Q2): Let $A$ = Top switch, $B$ = Bottom switch, and $Y$ = Light ($1$ = ON, $0$ = OFF). Flipping either switch toggles the lamp, which is an XOR function: $Y = \overline{A}B + A\overline{B} = A \oplus B$.

4. Applications & Key Takeaways
  • Chip Count Optimization: Replacing mixed AND/OR/NOT gates with NAND-only (IC 7400) or NOR-only (IC 7402) minimizes PCB inventory and propagation-delay skew.
  • Two-Level SOP Shortcut: Every minimized AND-OR SOP circuit converts directly to NAND-NAND without extra gates via bubble-to-bubble cancellation.
  • Applications: Two-way staircase lighting, digital parity generators, and standard-cell ASIC libraries.
Q2. State and prove DeMorgan's First and Second Theorems using truth tables. Also state Consensus & Distributive laws and simplify: (i) $F_1 = \overline{A}BC + ABC + A\overline{B}C + AB\overline{C}$, and (ii) $F_2 = (A+B)(A+C)(\overline{A}+\overline{B})$.6 Marks • SPPU Oct 2025 & PVG/SKN QB
SPPU Marking Split: DeMorgan's Statements & Equivalence (2M) · Truth Table Proof (1.5M) · Step-by-Step Algebraic Simplification (2.5M)

1. Definition / Core Principle: DeMorgan's Theorems relate AND and OR operations through complementation ("break the bar, change the sign"):
• Theorem 1 (NAND Equivalence): The complement of a product equals the sum of the complements: $\overline{A \cdot B} = \overline{A} + \overline{B}$.
• Theorem 2 (NOR Equivalence): The complement of a sum equals the product of the complements: $\overline{A + B} = \overline{A} \cdot \overline{B}$.

Diagram Explanation (How to Describe in Exam)
  • Theorem 1 (Left): Moving the inversion bubble from the output of an AND gate to its inputs converts the AND symbol into an OR symbol (Bubbled-OR).
  • Theorem 2 (Right): Moving the output bubble of an OR gate to its inputs converts the OR symbol into an AND symbol (Bubbled-AND). This lets us trace multi-level NAND/NOR circuits optically.

Useful companion laws: Distributive $A + BC = (A+B)(A+C)$; Absorption $A + AB = A$ and $A + \overline{A}B = A + B$; Consensus $AB + \overline{A}C + BC = AB + \overline{A}C$.

3. Step-by-Step Algebraic Simplification:

  1. Simplify $F_1 = \overline{A}BC + ABC + A\overline{B}C + AB\overline{C}$ (Units 1–5 QB Q11):
    • Using Idempotent Law ($X = X + X + X$), replicate $ABC$ three times so every minterm can pair with $ABC$: $F_1 = (\overline{A}BC + ABC) + (A\overline{B}C + ABC) + (AB\overline{C} + ABC)$
    • Factor using Distributive Law: $F_1 = BC(\overline{A}+A) + AC(\overline{B}+B) + AB(\overline{C}+C)$
    • Apply Complement Law ($X+\overline{X}=1$) and Identity Law ($X\cdot 1=X$): $$\mathbf{F_1 = BC + AC + AB}$$
  2. Simplify $F_2 = (A+B)(A+C)(\overline{A}+\overline{B})$ (SPPU Oct 2025 Q2b):
    • Apply Distributive Law $(A+B)(A+C) = A + BC$: $F_2 = (A + BC)(\overline{A}+\overline{B})$
    • Expand: $F_2 = A\overline{A} + A\overline{B} + \overline{A}BC + B\overline{B}C$
    • Apply Complement Law ($A\overline{A}=0$, $B\overline{B}=0$): $$\mathbf{F_2 = A\overline{B} + \overline{A}BC}$$
4. Applications & Key Takeaways
  • DeMorgan Shortcut: Break the complement bar and flip AND (·) to OR (+) or vice versa; essential for converting SOP to NAND-NAND and POS to NOR-NOR.
  • Consensus / Redundancy Tip: Always check for $AB + \overline{A}C + BC = AB + \overline{A}C$ in SPPU algebraic proofs to eliminate the third term immediately.
Q3. Compare Signed Magnitude, 1's Complement, and 2's Complement representations. Represent $-37_{10}$ and $-52_{10}$ in 8-bit formats, and perform $(151)_{10} - (76)_{10}$ and $(42)_{10} - (68)_{10}$ using 1's & 2's complement methods with overflow detection.6 Marks • SPPU Oct 2025 & SKN/PVG QB
SPPU Marking Split: 3-Way Comparison Table (1.5M) · 8-Bit Representations (1.5M) · Subtraction Steps & Overflow Diagram (3M)

1. Definition / Core Principle: In $n$-bit signed binary systems, the Most Significant Bit (MSB) acts as the sign bit ($0$ = positive, $1$ = negative). 2's Complement is the universal standard in modern ALUs because it provides a unique representation for zero and turns subtraction $A - B$ into addition $A + (\overline{B} + 1)$ without end-around carry circuitry.

Diagram Explanation (How to Describe in Exam)
  • Complementer Stage: The subtrahend $B$ is bit-inverted and incremented by $1$ (or via $C_0 = 1$ into the adder) to generate $-B$ in 2's complement.
  • Adder & Overflow Check: The adder computes $A + (-B)$. Signed overflow occurs if and only if the carry into the sign bit differs from the carry out of the sign bit: $V = C_{n-1} \oplus C_n$.

3. Worked Subtractions:

  1. Compute $(151)_{10} - (76)_{10}$ (SPPU Oct 2025 Q1c): Since $+151 > 127$, use 9-bit signed form: $+151 = 010010111_2$, $+76 = 001001100_2$.
    • 1's Complement: $\text{1's}(76) = 110110011_2$. Add: $010010111 + 110110011 = \mathbf{1}\;001001010_2$. Carry $= 1 \implies$ add end-around carry: $001001010 + 1 = 001001011_2 = \mathbf{+75_{10}}$.
    • 2's Complement: $\text{2's}(76) = 110110100_2$. Add: $010010111 + 110110100 = \mathbf{1}\;001001011_2$. Discard carry-out $1 \implies 001001011_2 = \mathbf{+75_{10}}$ ($V = 1 \oplus 1 = 0$, no overflow).
  2. Compute $(42)_{10} - (68)_{10}$ (8-bit Negative Result Case): $+42 = 00101010_2$, $+68 = 01000100_2 \implies \text{2's}(-68) = 10111100_2$.
    • Add: $00101010 + 10111100 = 11100110_2$ ($C_{out}=0$, MSB $= 1 \implies$ negative result, $V = 0 \oplus 0 = 0$).
    • Magnitude $= \text{2's}(11100110) = 00011001 + 1 = 00011010_2 = 26_{10}$. Final answer $= \mathbf{-26_{10}}$.
4. Applications & Key Takeaways
  • Why CPUs Use 2's Complement: Unique zero representation (`00000000`), unified adder/subtractor hardware, and no end-around carry loop.
  • Overflow Rule: Unsigned subtraction ignores carry-out, whereas signed 2's complement flags overflow iff $C_{in(\text{MSB})} \neq C_{out(\text{MSB})}$.
Q4. Convert $Y = AB + AC + BCD$ into Canonical SOP form. Minimize $F(A,B,C,D) = \sum m(1, 5, 7, 13, 15) + \sum d(0, 6, 12, 14)$ using a 4-variable K-Map and realize the minimized expression using NAND gates.6 Marks • SKN Q6 & Ajit Q5
SPPU Marking Split: Canonical SOP Expansion (1.5M) · 4-Var K-Map Table & Groupings (2M) · Minimal SOP & NAND Circuit SVG (2.5M)

1. Definition / Core Principle: In Canonical (Standard) SOP form, every product term (minterm) contains all input variables in either true or complemented form. A Karnaugh Map (K-Map) arranges truth-table minterms in Gray-code order so that adjacent cells differ by 1 bit, allowing redundant literals to be eliminated via $X + \overline{X} = 1$. Don't-care conditions ($d$) may be treated as $1$ only when they enlarge a group of actual $1$s.

2. Canonical SOP Conversion of $Y = AB + AC + BCD$: Multiply each non-standard term by $(X + \overline{X})$ for every missing variable:

  • $AB = AB(C+\overline{C})(D+\overline{D}) = ABCD + ABC\overline{D} + AB\overline{C}D + AB\overline{C}\overline{D} = m_{15}+m_{14}+m_{13}+m_{12}$
  • $AC = AC(B+\overline{B})(D+\overline{D}) = ABCD + ABC\overline{D} + A\overline{B}CD + A\overline{B}C\overline{D} = m_{15}+m_{14}+m_{11}+m_{10}$
  • $BCD = BCD(A+\overline{A}) = ABCD + \overline{A}BCD = m_{15}+m_7$
  • Combining unique minterms: $Y(A,B,C,D) = \sum m(7, 10, 11, 12, 13, 14, 15)$.

4. Applications & Key Takeaways
  • K-Map Grouping Rules: Always form the largest powers of 2 (Octet → Quad → Pair), allow wrap-around across edges/corners, and never include a group made purely of Don't-Cares ($X$).
  • Hardware Cost Reduction: Minimizing $F$ to 2 prime implicants ($BD + \overline{A}\overline{C}D$) cuts gate count to just three 2/3-input NAND gates.

SPPU Marking Split: Canonical POS Expansion (1.5M) · K-Map Maxterm Grouping (2M) · Minimal POS & NOR-NOR Diagram (2.5M)

1. Definition / Core Principle: In Product of Sums (POS) form, each sum term is a maxterm ($M_i$) representing an input row where the output equals $0$ (uncomplemented literal $= 0$, complemented literal $= 1$). On a K-Map, we place $0$s at maxterm positions, group the largest powers of 2 of $0$s (with optional don't-cares $X$), and OR the constant literals.

2. Canonical POS Conversion of $Y = (A+C+D)(B+C+D)(B+D)$ (Ajit Q6): Add $X\cdot\overline{X} = 0$ for each missing variable and apply $P + Q\overline{Q} = (P+Q)(P+\overline{Q})$:

  • $(A+C+D) = (A+B+C+D)(A+\overline{B}+C+D) = M_0 \cdot M_4$
  • $(B+C+D) = (A+B+C+D)(\overline{A}+B+C+D) = M_0 \cdot M_8$
  • $(B+D) = (A+B+C+D)(A+B+\overline{C}+D)(\overline{A}+B+C+D)(\overline{A}+B+\overline{C}+D) = M_0 \cdot M_2 \cdot M_8 \cdot M_{10}$
  • Taking the product of unique maxterms: $$\mathbf{Y(A,B,C,D) = \prod M(0, 2, 4, 8, 10)}$$

1. Definition / Core Principle: The Quine-McCluskey (Tabulation) Method is a systematic algebraic algorithm for minimizing Boolean functions (especially $\ge 5$ variables where K-Maps fail). It proceeds in two phases: (1) finding all Prime Implicants (PIs) by repeatedly combining minterms differing by 1 bit, and (2) constructing a Prime Implicant Chart to pick the minimum cover of Essential Prime Implicants (EPIs).

Diagram Explanation (How to Describe in Exam)

  • Essential PI Selection: Columns in the PI chart containing a single cross identify Essential Prime Implicants that must be included in the final minimal cover.

Q1. Design a Half Adder and Full Adder using Truth Tables and K-Maps. Realize a Full Adder using two Half Adders and an OR gate, and compare Half Adder vs Full Adder.6 Marks • Units 1–5 QB & SKN/Ajit/PVG
SPPU Marking Split: Truth Tables & K-Maps (2M) · Boolean Proof (1M) · Two-HA Full Adder SVG & Notes (2M) · Comparison Table (1M)

1. Definition / Core Principle: A Half Adder (HA) is a combinational circuit that adds two 1-bit binary numbers ($A, B$) to produce Sum ($S$) and Carry ($C$), without accepting a previous carry-in. A Full Adder (FA) adds three bits ($A, B, C_{in}$) — two operand bits plus an incoming carry — producing Sum ($S$) and Carry-out ($C_{out}$).

Q4. Explain the Carry Look-Ahead (CLA) Generator and why it is required. Derive the Carry Generate ($G_i$) and Carry Propagate ($P_i$) equations for a 4-bit CLA Adder (IC 74182) and draw its architecture.6 Marks • Units 1–5 QB & PVG Q25
SPPU Marking Split: Ripple-Carry Bottleneck (1M) · $P_i, G_i$ Derivation of $C_1..C_4$ (2.5M) · CLA Architecture SVG & Notes (2M) · Delay Comparison (0.5M)

1. Definition / Core Principle: A Carry Look-Ahead (CLA) Generator eliminates ripple-carry propagation delay by pre-computing all intermediate carries ($C_1, C_2, C_3, C_4$) simultaneously in two levels of logic directly from primary inputs $A_i, B_i,$ and $C_0$, reducing $n$-bit addition delay from $O(n)$ to $O(1)$ constant gate levels.

Diagram Explanation (How to Describe in Exam)
  • Carry Generate ($G_i = A_i B_i$): Produces a carry-out $1$ unconditionally whenever both $A_i=1$ and $B_i=1$.
  • Carry Propagate ($P_i = A_i \oplus B_i$): Passes incoming carry $C_i$ forward to $C_{i+1}$ when exactly one of $A_i, B_i$ is $1$. Because all $P_i$ and $G_i$ are available after 1 gate delay, the CLA block computes $C_1$–$C_4$ simultaneously in 2 more gate delays.

2. Recursive Derivation of Carry Equations: Starting from $C_{i+1} = G_i + P_i C_i$ and substituting backward:

  • $$C_1 = G_0 + P_0 C_0$$
  • $$C_2 = G_1 + P_1 C_1 = G_1 + P_1(G_0 + P_0 C_0) = G_1 + P_1 G_0 + P_1 P_0 C_0$$
  • $$C_3 = G_2 + P_2 C_2 = G_2 + P_2 G_1 + P_2 P_1 G_0 + P_2 P_1 P_0 C_0$$
  • $$C_4 = G_3 + P_3 C_3 = G_3 + P_3 G_2 + P_3 P_2 G_1 + P_3 P_2 P_1 G_0 + P_3 P_2 P_1 P_0 C_0$$

3. Delay Advantage: A 4-bit ripple-carry adder needs $4 \times 2 = 8$ carry gate delays ($2n$ for $n$ bits), whereas a 4-bit CLA computes every carry in just 2 AND-OR gate levels (total 4 delays to final $S_3$, regardless of bit width within a 4-bit slice), making it essential for high-speed CPU ALUs (like IC 74181 + 74182).

4. Applications & Key Takeaways
  • Speedup Factor: CLA reduces carry delay from $O(n)$ ripple steps ($2n$ gate delays) to $O(1)$ within each 4-bit block (just 2 AND-OR levels for $C_1$–$C_4$).
  • Tradeoff & Applications: Higher fan-in AND gates increase transistor area slightly; used inside 16/32/64-bit microprocessor ALUs (e.g., IC 74181 + 74182).

1. Definition / Core Principle: In a level-triggered JK Flip-Flop with $J=K=1$, if the clock HIGH pulse width $t_{PW}$ exceeds the flip-flop propagation delay $t_{pd}$ ($t_{PW} > t_{pd}$), the output toggles back and forth repeatedly ($0 \to 1 \to 0 \to 1 \dots$) within a single clock pulse, leaving the final state unpredictable. This oscillation is called the Race-Around Condition.

Diagram Explanation (How to Describe in Exam)
  • During CLK = 1 (Master Active, Slave Isolated): Master samples $J, K, Q, Q'$ and updates $Q_m$, while Slave receives $\overline{CLK}=0$ so its outputs $Q, Q'$ remain frozen (breaking the feedback loop!).
  • During CLK = 0 (Falling Edge Transfer): Master freezes $Q_m$, and Slave receives $\overline{CLK}=1$, copying $Q_m \to Q$. Thus $Q$ changes at most once per clock cycle on the negative edge.

2. Three Remedies for Race-Around Condition:

  1. Edge-Triggered JK Flip-Flop: Respond only during the brief positive or negative clock transition ($t_{PW_{\text{eff}}} \ll t_{pd}$).
  2. Master-Slave JK Flip-Flop (IC 7473/7476): Cascaded two-stage latch with inverted slave clock ensures feedback changes cannot re-enter Master during the same pulse.
  3. Clock Pulse Shaping: Ensure $t_{PW} < t_{pd}$ (narrow clock spike), though hard to guarantee across temperature/process variations.
4. Applications & Key Takeaways
  • Master-Slave Constraint: Inputs $J$ and $K$ must stay stable while $\text{CLK}=1$ to avoid ones-catching; edge-triggered FFs (IC 74LS76A) avoid even this limitation.
  • Applications: Frequency dividers ($f_{out} = f_{clk}/2$), ripple counters, and bounce-free toggle switches.

1. Definition / Core Principle: Hardware Description Languages (Verilog / VHDL) specify digital hardware concurrently for simulation and PLD/FPGA synthesis. Structural modeling connects pre-built gate/module instances like a circuit netlist, whereas Behavioral modeling describes algorithmic function inside procedural blocks (always in Verilog, process in VHDL) using if-else or case.

Diagram Explanation (How to Describe in Exam)
  • Structural vs Behavioral Synthesis: Structural code wires submodules explicitly (ideal for hierarchical datapaths like Full Adder from Half Adders), whereas Behavioral code lets the synthesizer pick optimal gates/LUTs (`always @(*)` with blocking `=` creates combinational logic; `always @(posedge clk)` with non-blocking `<=` infers edge-triggered Flip-Flops).
  • VHDL Equivalent: In VHDL, Structural uses `COMPONENT` + `PORT MAP` inside `ARCHITECTURE`, while Behavioral uses `PROCESS(clk)` with `IF rising_edge(clk) THEN`.

module half_adder(input a, b, output sum, carry);
    assign sum   = a ^ b;      // Dataflow XOR
    assign carry = a & b;      // Dataflow AND
endmodule

module full_adder_structural(input a, b, cin, output sum, cout);
    wire s1, c1, c2;
    half_adder HA1 (.a(a), .b(b), .sum(s1), .carry(c1));
    half_adder HA2 (.a(s1), .b(cin), .sum(sum), .carry(c2));
    or         G1  (cout, c1, c2);
endmodule

module mux4to1_behavioral(input [3:0] d, input [1:0] sel, output reg y);

            2'b01: y = d[1];
            2'b10: y = d[2];
            2'b11: y = d[3];

    end
